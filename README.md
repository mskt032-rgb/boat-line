# BOAT LINE

iPhoneのSafariで使う競艇予想Webアプリです。利用者の操作は「競艇場とレースを選ぶ」だけです。

- 公開先(GitHub Pagesを有効にした後): https://mskt032-rgb.github.io/boat-line/
- 情報の出典: [BOAT RACE公式サイト](https://www.boatrace.jp/)
- 別のサーバーや有料サービスは使いません(GitHub Actions + GitHub Pages のみ)

## しくみ

| 部分 | 場所 | 内容 |
|---|---|---|
| 自動取得 | `.github/workflows/update.yml`, `scraper/` | 日本時間6時〜23時ごろ、約10分ごとに公式サイトから取得してJSONに保存(各実行の最後に次の実行を予約。GitHubの定期実行は15分ごとの予備) |
| データ保存 | `data` ブランチ / `archive` ブランチ | data は毎回1コミットに置き換え(直近45日)。45日より古い日は1日1ファイルに圧縮して archive ブランチへ追記(1年以上残す)。日ごとの成績集計 `stats-days.json` は消さない |
| 画面 | `app/` | 静的サイト。予想はブラウザ内で計算 |
| テスト | `test/` | `npm test`(Node 20以上) |

### 取得のルール(控えめな頻度)
- 毎回 robots.txt を確認し、許可された場所だけ取得します。robots.txt が確認できないときは何も取得しません。
- 1回の実行で最大160件・8分まで、3秒以上の間隔(robots.txt に Crawl-delay があればそれに従う)。
- 公式サイトが 403 / 429 / 503 を返したら、その回はすぐやめて30分休みます(回避はしません)。
- 締切15分前を過ぎても展示が未発表のレースは展示を、締切5分前を過ぎたレースはオッズを、締切8分後を過ぎて結果がまだのレースは結果を、各実行の残り時間(開始から約8.5分まで)で約1分半おきに取り直す(1回最大40件)
- 選手のコース別成績は1人30日に1回まで(1回の実行で最大20人)
- 開催場一覧は2時間に1回まで、出走表は各レース1回(アプリ開始前などで締切前に取れなかったレースは、最後に回して30時間以内にあとから取得。その予想は「参考」と表示し成績に入れない)、直前情報・3連単オッズは締切25分前〜締切2分後に8分以上あけて、結果は締切8分後から(最大8回)。
- 1件の失敗で全体は止めず、前回取得できた正しいデータは残します。取得時刻・出典URL・エラーをJSONに記録します。

### 予想(`app/js/predict.js`)
1. 各艇を「能力(全国・当地勝率、級別、今節の平均着順)」「コース(選手のそのコースでの1着率・3連対率を全国の目安で割った値)」「モーター(モーター・ボート2連率)」「展示(展示タイム)」「ST(平均ST、展示ST、F持ち)」で6艇の中で比べて評価します。取れていない値は推測で埋めず、評価から外してその旨を表示します。
2. 進入後のコース並び(展示の進入。未取得なら枠なりと仮定し、そう表示)から、逃げ・差し・まくり・まくり差し・抜きの展開確率を出します。
3. 展開ごとに2着・3着の出やすさを掛け合わせ、3連単120通りの確率(合計100%)を出します。
4. 買い目は最大12点。A 的中重視 / B 回収率重視(推定確率×オッズ)/ C 穴狙い(20倍以上)。1号艇1着除外は初期ON、1号艇の1着が45%以上と見込まれるときは警告します。

### 保存と検証
**全レース自動記録**: 自動取得のたびに、締切前の全レースの予想(モードA/B/C × 1号艇1着 外す/外さない)を計算して記録します(`scraper/autopred.mjs`)。締切後は書き換えません。結果と合わせた `YYYYMMDD/autolog.json` を成績画面で集計します。

予想はレースを開いたときに端末内(Safariの保存領域)へ自動保存します。データや設定が変わると新しい「版」として追加し、前の版は書き換えません。締切後は保存しません。結果が出ると自動で照合し、的中率・回収率・確率の当たり具合(予想確率の帯ごとの実際の出現率、対数損失)を表示します。バックアップの書き出し・読み込みができます。

## 今後の課題(2026年12月16日ごろ、約3週間分のデータで試算して決める)
途中経過の確認は12月2日ごろ。予想の計算は、比較のためそれまで変えない。

1. 予想の重み付けを実際の結果に合わせて決め直す(特に2着・3着の決め方)
2. 競艇場ごとの特徴(1コースの勝ちやすさなど)を入れる
3. A・B・Cの役割分担
   - A: 1号艇の逃げは6点まで(堅いレースでも8点)+ 1号艇以外の押さえ。安い逃げの10〜12点買いはやめる
   - A は「確率の上から順」ではなく軸のある買い方も試算する(例: 1着固定 → 2着2艇 → 3着3艇のフォーメーション。2着の軸は1号艇1着のときの2着の確率から決める)。「1-3=245」(1着固定、相手本線1艇は2・3着どちらでも、ヒモ3艇=6点)や「1-3=24」(4点)の形も試算する
   - B: 1号艇以外が1着(差し・まくり)、オッズ100倍未満
   - C: オッズ100倍以上の万舟
4. B・Cを「期待値1倍以上だけ」にするか「最低6点」にするか
5. 確率の高すぎ・低すぎの補正(特に中穴の組)
6. 資金配分(本線・押さえ型、期待値型、トリガミ防止型、自信度型)。一律100円の回収率(選ぶ力)と、配分ありの回収率・収支額(実際の成績)、振れ幅・最大連敗(続けられるか)を並べて比べる
7. 場ごとの逃げやすさ(江戸川・戸田は逃げにくい等)を、たまった記録と一般的な傾向から入れる。入れる前後を同じレースで比べてから切り替える
8. 点数を本命の確率で変える(例: 本命50%以上は8点、未満は4点)
9. 締切前のオッズと確定オッズのずれを調べる(例: 11/27 徳山2R 3-6-1 は締切1分前62.3倍 → 確定85.5倍)。B・Cの期待値の計算と、期待値の帯ごとの実際の回収率を確かめる

方針: 的中率より回収率を優先する(的中率が下がりすぎない範囲で)。目標は回収率100%超え。3連単の払戻率は75%なので、まずは安定して75%を超えること。

メモ(11月25〜26日): 今のB(中穴)は買い目の78%、的中24本中23本が1号艇1着(「逃げ+ヒモ荒れ」)。回収率は90%前後。
「1号艇以外が1着のB」と同じレースで比べ、逃げ+ヒモ荒れが強ければAに組み込むことも検討する。
